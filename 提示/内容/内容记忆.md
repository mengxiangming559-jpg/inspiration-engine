# 一、系列信息

## 系列名称

《迷茫者的90天重启计划》

年轻人的迷茫、自我成长、行动与改变。

## 系列核心表达

不要求年轻人立刻找到人生答案。

慢一点，但不要停止前进。

# 七、内容创作原则

每一次新增内容时：

1. 不重复已经表达过的观点。
2. 尽可能寻找新的角度。
3. 注意前后内容之间的关系。
4. 保持创作者个人风格。
5. 记录内容产生的结果。
6. 根据数据进行下一次迭代。
